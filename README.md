# Vadik Mod (Forge 1.21.1)

Моб «Вадик»: своя 3D-модель (длинные волосы, чёлка, очки, ободок, наушник,
браслет, карго-шорты), книжка в руке, фразы по ПКМ, яйцо призыва в креативе.

## Как получить .jar для папки mods

### Вариант 1 — без установки чего-либо (GitHub Actions)
1. Создай репозиторий на github.com и загрузи в него содержимое этой папки
   (вместе с `.github/`).
2. Открой вкладку **Actions**, дождись зелёной галочки у «Build mod jar».
3. Внутри запуска скачай артефакт **vadikmod-jar**, в нём `vadikmod-1.0.0.jar`.
4. Положи jar в `.minecraft/mods` (нужен Forge 1.21.1, версия 52.x).

### Вариант 2 — локально
Нужны Java 21 и Gradle 8.8 (или `gradlew` из MDK Forge 1.21.1):

    gradle build

Готовый файл: `build/libs/vadikmod-1.0.0.jar`.
Если `forge_version` в `gradle.properties` не находится, поставь актуальную 52.x.

## Проверка в игре
Креатив → вкладка с яйцами призыва → «Яйцо призыва: Вадик».
Скин перерисовывается скриптом `tools/make_skin.py` (нужен Pillow).
